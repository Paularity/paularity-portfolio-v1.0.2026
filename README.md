## Featured Platforms

### BCI (Next-generation Cooperative Suite)
An integrated ecosystem covering identity, accounting, content, and multi-channel front-ends for cooperative organizations.

- **BCI.NEXTCOOP** — C# / ASP.NET Core backend + Flutter mobile + microservices. Multi-platform cooperative management system with backend APIs, workload processing, and mobile apps for admin and end-users.
- **BCI.NextCoop.AdminPortal** — Next.js 16 / React 19, Kendo React 15, NSwag, Next-Auth 5. Admin dashboard with data grid, form components, and server-side API client generation from the .NET backend.
- **BCI.NextCoop.PublicWeb** — Next.js 16 / React 19, GraphQL, Framer Motion, Tailwind CSS, shadcn/ui. Public-facing website with animation, GraphQL-driven content, and responsive design.
- **BCI.Accounting** — C# / ASP.NET Core 9, EF Core, MediatR, Serilog. Clean-architecture accounting platform (Domain/Application/Infrastructure) with CQRS and support for invoices, expenses, payments, vouchers, and reporting.
- **BCI.IDP** — C# / ASP.NET Core 9, Duende IdentityServer 7.4, EF Core, Azure Storage/Queues. Identity provider managing OAuth 2.0 flows, user identity, and token lifecycle.
- **bci.api** — Node.js / Strapi 5.46, SQLite/PostgreSQL. Headless CMS + GraphQL API serving content, permissions, and media across BCI apps.
- **bci.web** — Next.js 16 / React 19, Strapi, GraphQL, RSC, shadcn/ui. Marketing site monorepo with decoupled CMS and server-driven content.

### Blackfort (BF) — Financial Services
- **BF.LeaseManagement** — C# / ASP.NET Core 9 + Flutter + Blazor components. Comprehensive lease management with API, mobile client, shared components, and DDD-style domain modeling.
- **BF.ELOA** — C# / ASP.NET Core test project supporting the equity-line-of-account workflow for the Blackfort finance platform.

### CAEMC — Citizen Engagement
- **CAEMCOnline** — C# / ASP.NET Core + Angular + IdentityServer. Multi-project citizen portal with public portal, IDP, workload processor, and role-based access.
- **CAEMCMobileApp** — C# / ASP.NET Core 9 backend + Flutter + Azure Storage/Tables/Queues. Mobile-first citizen engagement app with cloud storage and queue-based processing.

### CIAM
- **CIAM** — C# / ASP.NET Core, Duende IdentityServer, Blazor Web. Comprehensive customer identity & access management: admin portal, API services, and identity provider.

### PSACC — Container Logistics
- **BookingPlatform** — C# / ASP.NET Core 7, Azure Functions, Telerik Razor, Azure Storage, Serilog. FCL/LCL container booking platform for Philippine Asia Span Carrier (API + back-office + serverless + email templates).
- **PSACC.Web.BlazorWASM** — C# / Blazor WebAssembly (.NET 7). Reusable NuGet template for spinning up standardized PSACC web apps.
